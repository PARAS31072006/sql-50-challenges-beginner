# 📝 SQL Practice & Challenges

Welcome! This repository contains SQL challenges and practice exercises designed to help you strengthen your database querying skills.

---

### 📌 Database Setup & Roadmap

* **Database Setup:** The core dataset is available in `contoso_100k.sql`. Make sure to restore/import this file into your SQL environment before attempting the exercises.
* **Basic Selection Tasks:** Head over to the **Basic Selection** directory to find foundational SQL tasks and challenges designed for you to solve on your own.
* **Progressive Difficulty:** Challenges are structured progressively—scaling gradually from beginner querying to advanced SQL operations. New levels and complex problems will be added continuously!
